# dakaholding.sa

Static one-page site for Daka Holding. No build step.

- `index.html` — English
- `ar/index.html` — Arabic (RTL)
- `styles.css`, `favicon.svg`, `logo.svg`, `logo-light.svg`, `og-image.png`

Preview locally: `python3 -m http.server 8000` in this folder, then open http://localhost:8000
